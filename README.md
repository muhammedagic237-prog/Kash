# Kash

A simple, fast personal expense tracker built with React + TypeScript + Vite.

All data is stored locally in your browser — no accounts, no servers, complete privacy.

## Features

- **Dashboard** — monthly spending overview with pie and bar charts
- **Add / Edit Expenses** — quick amount buttons, category picker, date selector
- **History** — search, filter by category, grouped by date, CSV export
- **Budgets** — per-category monthly spending limits with progress tracking
- **Settings** — currency selector, data export, clear all data
- **Dark Mode** — automatic, follows system preference

## Tech Stack

- React 19 + TypeScript
- Vite
- React Router
- Recharts (charts)
- Lucide React (icons)
- localStorage (persistence)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
